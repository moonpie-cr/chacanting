# 🧋 像素茶餐廳 · Pixel Cha Chaan Teng

> 🏮 一间住在 8-bit 世界里的港式茶餐厅：推门进店 → 点单 → 选座 → 等伙计上菜。

📄 单个 HTML 文件 · 📦 无依赖 · 🌐 简 / 繁 / EN / RU

---

## 🚀 快速开始

1. ⬇️ 下载 `cha-chaan-teng.html`
2. 🖱️ 用浏览器打开，开玩！

🌍 **部署到 GitHub Pages**：改名为 `index.html`，在 Settings → Pages 里选择从 `main` 分支部署。

## 🗺️ 流程

🏙️ 港风街头 → 🍞 店内点单 → 🪑 挑一张台 → 🍽️ 卡座上菜 → 💰 埋单

（🥡 外卖：落单拿号就完成）

## 🛠️ 修改菜单

📝 编辑 `<script>` 里的 `MENU` 数组，菜名按 简 / 繁 / EN / RU 的顺序写：

```js
{ id: "mt", cat: "drink", price: 22, type: "drink", tea: true,
  n: ["港式奶茶", "港式奶茶", "HK Milk Tea", "Гонконгский молочный чай"] },
```

🎨 新菜品还要在 `SPRITES` 里加一张 16×16 的像素图，键名用菜品 `id`。

⚠️ 内嵌字体只截取了页面现有的字。新加的字如果字体里没有，会用系统字体显示，需要用 `pyftsubset` 重新截取字体。

## 💾 数据

🔒 订单只存在你自己浏览器的 `localStorage` 里，不会上传到任何地方。
